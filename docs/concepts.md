# Core Concepts

## Dyad vs. Triad

### Dyad (2 people)

**Use for:**
- Collaboration on execution
- Low-stakes choices
- Feedback loops
- Routine approvals

**Dynamics:**
- Fast, direct
- No tiebreaker needed (assumes good faith)
- If stuck, escalate to triad

### Triad (3 people)

**Use for:**
- Strategic decisions
- Resource allocation
- Hiring/firing
- Directional shifts
- Conflict resolution

**Dynamics:**
- Built-in tiebreaker (2/3 moves)
- Dissent recorded, not blocked
- Prevents both autocracy and gridlock

---

## Decision Thresholds

Not every choice needs a triad. Ask:

1. **Does this affect others' work?** If yes → triad candidate
2. **Is this reversible?** If no → triad candidate
3. **Does this commit significant resources?** If yes → triad candidate
4. **Will this create precedent?** If yes → triad candidate

**Rule of thumb:** If you're asking "should this be a triad?", it probably should be.

---

## The 2/3 Rule

**2 agree = decision moves**
- Majority sufficient for action
- Prevents veto-by-one paralysis

**1 dissents = recorded, published**
- Objection documented in decision log
- Not suppressed, not debated to death
- Creates audit trail for future review

**Why this works:**
- Speed: decisions don't require unanimity
- Integrity: dissent isn't erased
- Learning: future triads can see where past objections were right/wrong

---

## Authority Morphs to Competence

Triangle assumes:

- The person with most relevant expertise should carry more weight
- But all three voices must be heard before weighting applies
- AI tracking ensures dominant personalities don't monopolize

**Example:**
- Technical decision → engineer's voice weighted higher
- But: marketer and CEO still get full hearing
- AI ensures speaking time equity before competence weighting

---

## Living Architecture

Triangle is not a fixed hierarchy. It's a **living architecture**:

- Triads form around decisions, then dissolve
- Same person may be decider in one triad, dissenter in another
- Authority flows to where competence lives for *this* decision

This contrasts with:
- Org charts (fixed authority)
- Consensus models (everyone must agree)
- Autocratic models (one person decides)
